# 章节频道 AgentBot 导入 Spec

- 状态：MVP-1 增量，2026-11-06；本文件覆盖基线中关于本导入流程必须登录及不接入 AI 的限制。普通分享和其他写操作仍按原基线鉴权。
- 目的：让共读者将公开的钉钉听记、飞书妙记链接或文字发送给频道 AgentBot，自动整理成易读的公开章节分享。平台不实现录音或语音转写。

## 用户流程

用户从章节频道打开 AgentBot，粘贴互联网可访问的来源链接或已整理文字，选择章节后提交；无需登录。提交即公开，界面明确说明内容会公开、发送模型处理及姓名遮盖的局限。处理成功后显示分享及返回频道入口；失败保留输入并给出重试或粘贴导出文字的路径。默认不公开来源链接，避免源页面泄露姓名。普通用户内容仍可按原有规则发布。

来源页面文字可能由前端加载、需要验证或过期；可读取不代表每种网页实现都能被解析。首期链接限定飞书、钉钉域名，无法读取时允许粘贴导出文字。外链和文本均是不可信数据，不能执行其指令。提交者负责确认内容可供公开及模型处理。

## 内容及数据关系

一条导入产生一个 ContentItem，关联当前选择的单个章节，供该章频道排序和阅读；同一场共读若需多个章节，可分别导入。ContentItem 作者可为空，仅 AgentBot 导入允许为空；保存来源类型、格式化结果和来源 URL（服务端私有，不进公开 DTO）；不存原始文稿。导入结果保存标题、摘要、分节标题、段落与列表；模型需尽量沿用已有整理稿，不虚构发言、经文或事件。姓名在标题、摘要和所有段落统一替换为部分遮盖，无法确定的说话人使用泛称；不宣称能够完全匿名。失败不发布原文。模型提供结构，前端只以文本节点呈现，绝不渲染来源 HTML。

游客导入无账号归属，服务端保存随机管理令牌摘要，令牌仅在发布后发回当前浏览器；当前设备可以撤回，管理员可治理。令牌不进入公开 DTO、日志或 URL，丢失后由管理员处理。匿名访客限频，同源写入、幂等和目标站点限制适用；防止访问内网及重定向绕过。对外不泄露来源 URL、原始名字及私有字段。来源、模型输出与用户文本不能驱动工具执行。

## 阅读效果及验收

频道保持原有阅读量/最新排序、有效阅读和互动。导入内容在详情中采用本产品浅色纸感、清晰标题、摘要、可跳转目录和分节阅读，借鉴参考图的信息层次，不复制暗色主题。手机单列，长文本可读、自动换行；普通分享不改变。

验收：游客提交粘贴文字可发布到所选章；授权公开链接成功提取时可发布，不可读取时明确失败；标题、摘要、节名和正文均按模型输出遮盖；公开 API 不返回原链接、管理令牌或原始稿；同一提交幂等；本机可撤回、其他访客不可撤回、管理员可管理；失败不存公开内容；手机及桌面阅读无溢出。姓名识别依赖模型且无法保证完整，应以真实样本评估漏遮率；不提供实时录音、转写、自动识别未经指定的其他章节或通用网页采集。

# 章节频道领读类分享

独立制作的章节材料进入现有 `ContentItem` 频道，不作为外链卡片处理。它与现场记录分享并列，沿用章节频道的阅读排序、有效阅读、评论、隐藏/删除、审计和媒体鉴权。

## 类型与权限

- `FIELD_NOTE`：现场记录分享，沿用社区分享流程。
- `AGENT_NOTES`：游客共读助手整理的共读纪要，保留现有免登录发布规则。
- `LEAD_READING`：领读类分享。由内容管理员发布，使用结构化正文；详情显示“平台领读 / 领读分享”。

结构化正文复用安全文本渲染（提要、目录、分节、有限标记）。导入资料的插图经站内媒体流程上传关联，分享详情只渲染整理后的正文。领读、共读纪要和现场记录在频道卡片及详情中明确标注。

## 第十章材料

`prisma/seed/channel-materials/chapter-10-family.json` 是随附 HTML 包转成的结构化正文。第十章频道的管理员发布表单中勾选“发布为领读类分享”，粘贴 JSON 并上传包内四张插图。材料说明其为现代生活应用，不是共读实录或唯一经义解释。原网页互动和动画不作为频道功能导入。

图片走现有格式检查、大小限制、内容关联和每次读取显隐检查。原 HTML 包没有附带逐字校核记录；用户于 2026-11-13 确认正文与四张插图的公开授权，现已发布至 Production 第十章频道，内部审计保留 `unreviewed` 状态。此授权不等于逐字校核，页面不将材料标为已校核。

## 第五十七章「真实」

`prisma/seed/channel-materials/chapter-57-truth.json` 提供领读分享的摘要和分节。项目播种时以不可登录的平台账号创建固定的 `LEAD_READING` 记录并记审计，内容由管理员管理。重复运行保留该记录的显隐与已有内容。访客从第57章频道打开分享详情，再经「打开完整领读」进入站内独立长页。页面直接使用 `sites/chapter-57-reading/dist/` 的 HTML、样式、脚本和封面。详情和长页共用有效阅读接口及当日去重规则。

验收时把问题反过来问。绕过频道，用隐藏前复制的旧地址访问 HTML、样式、脚本或封面，还能读到内容吗？每个文件请求都查分享的当前发布状态，响应不缓存。第57章这套材料的文件路径由代码指定，分享正文和外部来源链接继续按原规则处理。

## 第五十七章现场领读

洛远和禅桥道长的现场领读各为一条独立的 `LEAD_READING`，正文和插图位于 `prisma/seed/channel-materials/`。节标题中的时间对应各自的逐字稿。原经文以项目录文为准，现场解释按分享者归属整理，发布审计标记逐字稿未经校核。

结构化领读的节可带 `illustration`，填写本次发布时关联的图片 `mediaId`、替代文字 `alt` 和图注 `caption`。发布时校验图片已上传、归发布者所有且用于本条分享，详情只从公开分享的媒体列表取图。分节图在所属小节内显示，其余图片继续走原有封面及图集流程。图片和 Range 请求沿用媒体接口的逐次显隐检查。

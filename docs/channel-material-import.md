# 章节频道领读类分享

独立制作的章节材料进入现有 `ContentItem` 频道，不作为外链卡片处理。它与现场记录分享并列，沿用章节频道的阅读排序、有效阅读、评论、隐藏/删除、审计和媒体鉴权。

## 类型与权限

- `FIELD_NOTE`：现场记录分享，沿用社区分享流程。
- `AGENT_NOTES`：游客共读助手整理的共读纪要，保留现有免登录发布规则。
- `LEAD_READING`：领读类分享。由内容管理员发布，使用结构化正文；详情显示“平台领读 / 领读分享”。

结构化正文复用安全文本渲染（提要、目录、分节、有限标记）。插图经站内媒体流程上传关联，公开页不加载原 HTML 或原始站点地址。领读、共读纪要和现场记录在频道卡片及详情中明确标注。

## 第十章材料

`prisma/seed/channel-materials/chapter-10-family.json` 是随附 HTML 包转成的结构化正文。第十章频道的管理员发布表单中勾选“发布为领读类分享”，粘贴 JSON 并上传包内四张插图。材料说明其为现代生活应用，不是共读实录或唯一经义解释。原网页互动和动画不作为频道功能导入。

图片走现有格式检查、大小限制、内容关联和每次读取显隐检查。原 HTML 包没有附带逐字校核记录；用户于 2026-11-13 确认正文与四张插图的公开授权，现已发布至 Production 第十章频道，内部审计保留 `unreviewed` 状态。此授权不等于逐字校核，页面不将材料标为已校核。

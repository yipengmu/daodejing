# MVP-1 独立 Preview 与发布检查

本地第一版已实现；以下项是从本地转入可供真实用户使用环境前的验收门槛。尚未执行的项保持未勾选，不代表需要重定产品规则。

- [ ] 为本项目配置独立 Neon、阿里云 PNVS、腾讯 SES/COS 和高德应用；确认 Preview / Production 资源和域名隔离。没有其他项目的数据或凭据。
- [ ] 核对目标数据库主机及分支，建立可恢复备份，再手动执行 `db:migrate`、`db:seed`。验证 81 章和 9 个地点、迁移历史、公开字段；不在 build 中迁移。
- [ ] 真实短信与邮箱分别验收注册、重发/过期/错误码、一次性消费、密码登录、手机号 24 小时重置限制、恢复邮箱和旧会话失效；检查服务商失败与费用限额。
- [ ] COS 桶保持私有，配置本站上传 CORS；真实图片/音频验证大小/时长/元数据、上传失败重试、隐藏后旧读取地址和 Range 拒绝、未隐藏内容正常播放。对象内容不进入日志。
- [ ] 高德域名白名单、安全代理、REST 搜索和 GPS 转换通过；固定/临时点类型明确；种子中缺少坐标的地点通过真实 POI 选择补全，拒绝定位仍可完成提交。手机实测聚合点、外部导航与返回。
- [ ] 在 Neon 多连接环境并发验证阅读去重、计数、幂等提交、验证码消费/重置额度及数据约束。PGlite 单进程测试不代替此项。
- [ ] 在可启动 Chromium 的环境运行 `npm run test:e2e`，通过 12 项桌面/手机旅程；在实际 iOS/Android 浏览器补查安全区、软键盘、旋转、抽屉和音频。补验游客 VOC 成功回执、退出确认与草稿清理。
- [ ] 独立 Vercel Preview 验证 SPA 深链接、所有 `/api/*` 改写、同源 Cookie/来源校验、媒体文件流及 HEAD/Range、未配置服务错误、构建不含密钥。当前配置尚未云部署验证。
- [ ] 通过操作者 CLI 只授予真实管理员；验证管理任意内容及审计，普通用户无法越权；开发账号和测试资源不进入 Production。
- [ ] 保留真实经文来源/校核状态及古注缺失提示；上线前复核公开地点没有住宅房号/私人联系方式，分享匿名提示准确。

## 部署与回退操作

1. 在独立 Preview 完成迁移、种子及上方场景，记录 commit、迁移列表、测试结果和资源目标。
2. 发布前备份数据库并确认可以恢复；在业务低峰迁移。当前迁移是首次建库，不能对已有其他项目的数据库执行。
3. 应用与数据库兼容后发布生产版本，再检查读经、登录、分享、VOC、地点和媒体显隐。
4. 应用故障优先回退到最近验证过的应用版本，保留数据库与媒体。新增迁移优先兼容旧版本，避免让应用回滚依赖删表。
5. 数据问题先停止相关写入并保留审计；按已验证的备份恢复方案处置。不要自动运行 DROP、删除迁移历史或覆盖原始种子；恢复操作应明确目标与数据影响后单独执行。

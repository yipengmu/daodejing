# 移动端阅读体验 Spec · MVP

> 状态：设计提案，待用户评审和真实用户验证；研究日期：2026-10-31。适用于移动 Web，桌面端沿用信息关系并独立适配。与主产品 Spec 和页面动线 Spec 配合使用。

项目统一视觉与阅读排版规则见 [统一设计 Spec](./design-guidelines-spec.md)。本文件继续约束移动阅读的交互、手势和状态；若视觉变量描述与统一设计 Spec 不一致，以统一设计 Spec 为准。

## 1. 目标与边界

读者打开产品后，可以找到一章，以左右翻书的方式阅读原文；本章注释作为同一章节的辅助面从底部上滑查看，本章频道及大家的分享是阅读中可见的次级入口。阅读无需登录；发布和互动按现有权限规则执行。全局导航仍为「读书 / 发现 / 我的」，阅读页进入专注模式，退出阅读即可恢复全局导航。

本提案以一期已有的目录、原文、来源、可用注释、字号、进度记忆、章节切换和频道为范围。若某章尚无可靠注释或解读，不显示虚构内容或假入口；版本、来源与原文以内容数据的实际情况为准。背景主题、字体选择、划线、书签、搜索、朗读与翻页动画属于后续候选，不在本次设计中暗示已上线。

**批判性问题：上滑注释与正文翻页、注释自身滚动以及系统边缘返回发生冲突时，读者能否准确完成操作？** 上滑从注释把手发起，左右翻页按手势方向识别；同时提供可点击的注释与前后页入口，验证半屏滚动、系统返回及文字选择。默认只展示原文，注释和频道都有清楚可见的入口。

## 3. 阅读视图与尺寸起点

- 气质：安静、克制、有书卷感。使用暖白纸色和近墨色正文，弱化边框、阴影、仪表盘和装饰；避免仿古纹理、印章和难辨识的书法字。
- 色彩起点：背景 `#FAF8F2`，正文 `#282821`，次级文字 `#5D6058`，辅助线 `#D9D8CF`，操作/选中 `#436658`。颜色是设计稿起点，需按最终字体、字号验证对比度，不能仅依赖颜色传达状态。
- 在 375 CSS px 视口上，正文左右内边距建议 24 px；书页内容单列，随窄屏缩减边距，保持文字自然换行。章节号、标题、版本来源、原文、章末动线依次排列，以留白而非卡片分隔。
- 原文字体使用系统中文宋体/衬线字体栈，缺字或设备无衬线字体时可回退系统可读字体；正文默认 20 px、行高约 1.9，段间距约 1 行。字体、断句和段落以可靠底本为准，**不**为视觉效果增删原文。注释不小于 16 px，颜色及字号需验证可读性。
- 字号提供 4 档示例 18 / 20 / 22 / 24 px，默认 20 px；切换即时生效并记住本机选择。浏览器系统缩放仍可用，排版应重排而非横向截断。字号、行高和字数是原型起点，须经不同设备与用户验证。
- 控件触控区域设计目标至少 44 × 44 CSS px，图标可更小；正文内注释标记要有足够间距，并在注释列表提供等价入口。适配安全区、键盘与浏览器工具栏，不将正文或章末操作压在遮挡区域。参考 [W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) 和 [重排](https://www.w3.org/WAI/WCAG21/Understanding/reflow)。

## 4. 主路径与页面状态

| 步骤 | 阅读者看到什么 | 操作与结果 |
| --- | --- | --- |
| R01 读书目录 | 书名、简短版本说明、继续阅读行（有本地进度时）、按序排列的 81 章目录。章节号与底本首句组成索引；不把首句假称正式章名。 | 首次访问选择任一章；再次访问可继续上次章节和位置。目录完整滚动，当前章有文字标识。 |
| R02 章节首屏 / R02-C 收起浮条 | 正面为章节原文，底部常驻一条收起态内容浮层；首次进入章节默认收起，不遮挡原文。短横把手下轮换本章注释摘要或频道按有效阅读数排序的分享，带清晰的内容类型标识。 | 正文区左右滑翻页；只从把手发起的纵向拖动调整浮层高度，横向手势不改变浮层状态。点击把手展开进入半屏。点击预览打开对应分区。 |
| R02-N 半屏浮层 | 非模态浮层约占可用视口一半，上方原文仍可操作；浮层内切换「注释 / 本章分享」。注释先「当代注释」再「河上公」，分享展示本章按有效阅读数排序的内容与频道入口。 | 从把手继续上滑至顶部或下滑收起；内容区独立纵向滚动。点击分享打开详情，进入频道可浏览完整内容；返回原阅读位置。 |
| R02-T 顶部浮层 | 浮层提升到顶部安全区附近，注释或分享拥有更大的阅读空间。 | 内容区独立滚动，从把手下滑回半屏，再下滑收起；顶部状态若已遮住原文，先降回半屏再操作原文。 |
| R02-F 字号设置 | 从「更多」进入次级设置面板，显示 A−、字号、A+ 和关闭。 | 调整即时预览，重新分页后保持原文锚点；触及最小/最大值时禁用相应操作。 |
| R02-E 章节末页 | 原文末页继续保留本章浮条；末页提供本章分享摘要或空态及清晰的「进入本章频道」，以及下一页/下一章提示。 | 左滑继续进入下一章首页；也可点「下一章」。点击频道进入 R03，返回原页；第 1/81 章不存在的方向禁用。 |
| R03 章节频道 | 当前章节上下文与本章分享，按有效阅读数/最新浏览。 | 查看分享、评论或发布；返回阅读保留章节和原文位置。阅读正文不会混入他人观点。 |

### 控件与状态细节

- **目录**：R01 为读书 Tab 的完整目录。阅读内「目录」打开可关闭的目录层，指示当前章节，选章后关闭并进入所选章；关闭或系统返回则回到原阅读位置。不要要求用户回到顶部才找到目录。
- **入口与层级**：顶部提供目录、章序、更多；底部常驻浮条及把手，内容为本章注释或本章按有效阅读数排序的分享的摘要，附类型标签。浮层展开后有「注释 / 本章分享」切换及进入完整频道的入口。章节末页另给出分享摘要或空态和频道入口；不要把分享伪装成古注。字号等设置收进更多。
- **浮层三个停靠位**：收起态约一行摘要；半屏态约可用视口的 50%；顶部态距安全区顶部保留空间。数值为设计起点，随屏幕尺寸与安全区适配。上滑把手逐级展开、下滑逐级收起；点把手/状态按钮提供同等操作。无背景遮罩、不锁定背景，浮层覆盖范围之外的原文保持可操作；顶部状态覆盖正文时先降回半屏。当前章节变化时，浮层立即切换为新章内容、清空旧章加载数据并重置内容滚动；不跨章混用分享。
- **浮条动态提示**：使用当前章有权限展示的已发布内容，区分「当代注释」「河上公」「本章分享」，可慢速轮换，避免闪烁；停留/聚焦及系统减少动态效果时暂停，并保证可手动打开。无分享时显示「本章还没有分享」和进入频道入口，不伪造热度、作者或示例为真实内容。按有效阅读数排序的分享沿用章节频道的排序和可见性规则。
- **左右翻页**：左滑下一页、右滑上一页。长章节可分为多页；当前章末页左滑进入下一章首页，当前章首页右滑回上一章末页；第 1 章首页和第 81 章末页不循环。提供清楚命名的上一页/下一页等价按钮，按钮可在轻菜单中找到，并提供屏幕阅读器操作。翻页不依赖拟物动画；尊重减少动态效果设置。
- **手势冲突**：高度切换只响应从浮层把手发起的上下拖动；内容区上下滑动只滚动浮层内容，原文区左右滑动翻页。半屏下未被遮挡的原文仍可翻页，浮层内手势不传给原文。识别明显横向手势才翻页，预留系统边缘返回区域；长按选文、点击链接、浏览器返回和辅助技术操作不得触发翻页。实际阈值和误触需真机验证。
- **进度记忆**：阅读时保存章号与稳定的段落锚点及段内位置；恢复时数据变更找不到锚点则回该章开头。匿名用户也能在同一浏览器继续阅读；清除浏览器数据后可能丢失，不承诺跨设备同步。首次访问不显示虚构的百分比。切换字号或打开面板保持当前段落可见。
- **章节来源**：版本/来源入口展示真实来源和版本信息；内容不可用时给出原因或稍后重试以及目录返回，不展示占位经文冒充内容。
- **注释层次与写法**：半屏内部先显示「白话注释」，再显示「河上公」；白话注释按原文逐句对应，使用直白释义解释句中词义和句意，不延伸为整章思想评论、人生建议或现代观点。必要语境说明与逐句释义明确分开。各条按原文顺序组织，不嵌套卡片；出处和实际作者/整理者以低调来源信息或来源详情提供。河上公对应经核验的古注原文。逐句对应关系、来源或审校状态不可靠时，标明待补/待核，不伪装为已完成注释；每层独立维护，一层缺失不隐藏另一层。
- **注释来源与定位**：已有 `youth_easy_read` 内容仅作第一层候选，展示前需确认来源、质量和使用许可；`heshanggong_interpretation` 是现代转述，不能标成河上公古文原注。河上公古文须补齐可追溯底本、章节对照和审校；标记与条目保持对应。非模态浮层不锁定焦点；通过按钮操作时维持明确焦点顺序，收起后可回到原文。分享在浮层仅作当前章预览，完整内容属于章节频道。
- **需要反向核对的问题**：如果阅读正文与河上公古注依据的传本在分章或文字上有差异，读者会不会误以为两者逐字对应？导入前逐章核对对应关系，在来源中标示古注底本；不能可靠对应时标为待核，避免展示误导性的逐句定位。
- **导航与重排**：向后跨章从新章首页开始，向前跨章回上一章末页；目录选章从首页开始。系统返回、目录关闭、设置关闭和频道返回均保留原文锚点。字号、方向、视口变化触发重新分页，仍定位到原锚点；确保大字号内容完整可读、不出现双向滚动。

## 5. 原型验证计划

首轮建议 5–8 位不同阅读习惯的用户，用 320、375 和大字号场景走查；这是探索性样本，不能当作统计代表。记录首次任务完成、误触、找入口时间和口述原因，并按现有产品 Spec 的目标评估：

1. 从默认入口找到第 30 章并打开原文；观察章节索引是否易扫描。
2. 左右翻页并跨章，再用等价按钮完成；观察误触、系统返回冲突与章节边界理解。目标任务完成率 ≥90%。
3. 在浮条、半屏、顶部三态之间切换，分别滚动内容及在半屏外左右翻页；识别当代注释和河上公，记录误触与入口发现率。
4. 查看每章底部按有效阅读数排序的分享、进入频道并返回；跨章后确认浮层内容属于新章，记录用户是否误把分享视为古注。
5. 通过更多菜单调大字号，在窄屏、系统返回与屏幕阅读器下检查重排、阅读顺序、焦点、内容截断及位置恢复。

验证通过前，色值、字号档位和控件位置均为设计假设；真实底本、注释与来源还须依内容准备流程确认。
